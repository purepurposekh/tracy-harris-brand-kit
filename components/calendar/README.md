# Calendar

A Tracy Harris Co calendar component set inspired by the useful structure of Untitled UI calendar examples, rebuilt in the Tracy Harris brand kit language.

## Variants

- Month view, seven-column campaign and delivery overview
- Week view, scrollable time grid with day headers
- Day view, single-day schedule for high-clarity planning

## Brand guidance

Use `data-brand="tracy"` for the parent Tracy Harris Co expression. The component references semantic tokens from `styles/tokens.css` only, including surfaces, ink, accent, border and typography.

The tone should feel editorial, calm and operational. Avoid colorful SaaS category palettes unless the target brand is FRESH and the content is explicitly FRESH framework material.

## Files

- `calendar.css`, shared component styles
- `variants/showcase.html`, static showcase of month, week and day views
