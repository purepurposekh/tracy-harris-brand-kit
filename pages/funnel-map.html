Variation A

Dual CTA · quiz + workshop

Tracy's Ch 4 close presents two options. The prospect picks based on her own urgency: faster diagnostic via quiz, or deeper live experience via workshop.

  • Mini class → quiz OR webinar
  • Quiz feeds smart link logic
  • Webinar → post-workshop smart link → quiz or application
  • Both paths converge at FFB application or alternate

Use when a workshop is upcoming

Variation B

Quiz only · fast path

No webinar mentioned. Mini class drives straight to quiz. The quiz result page plays a 5-10 min Tracy deep-dive video for her loudest pillar (Build / Sell / Lead) so she still gets depth.

  • Mini class → quiz
  • Result page personalised by lever
  • Pillar deep-dive video replaces webinar depth
  • FFB application invitation tied to her pillar

Use when no workshop is running

Variation C

Workshop only · full focus

All energy on filling the live workshop. Mini class CTA is single: register for the next workshop. Quiz isn't mentioned on the class but shows up at the end of the workshop via the smart link.

  • Mini class → workshop registration
  • Workshop CTA → smart link → quiz or application
  • Quiz catches anyone who attended but didn't apply

Use in pre-workshop launch weeks

Reading the map.

  • Variation toggle · the gold diamond at the top decides which CTA closes the mini class. Same class video, three different Ch 4 endings Tracy records once.
  • Smart link · single URL Tracy speaks at the end of the workshop. The page reads AC tags and renders one of three branches.
  • Pathway PDF · the Freedom Filled® Pathway Map ships to her inbox on opt-in. Tangible value she keeps regardless of whether she takes the next step.
  • Pillar deep-dive video · three short Tracy recordings (Build / Sell / Lead). The quiz result page in Variation B plays the one matching her loudest pillar.
  • FFB application · paid refundable fee, Tracy reviews. Accepted → welcome onboarding. Not right fit → fee refunded + alternate next step.
  • Alternate next step · for prospects the quiz flags as not-yet-FFB. Nurture sequence, alternate product, or free PDF, depending on what fits her profile.
