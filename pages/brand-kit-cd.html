How to use with Claude Design

Claude Design ingests tokens + CSS to infer a brand. Either approach works:

  1. In a new Claude Design project, paste the JSON directly (use the copy button above), or attach the downloaded tracy-harris-co-tokens.json file.
  2. Point Claude Design at the live CSS for richer context: https://cdn.jsdelivr.net/gh/purepurposekh/tracy-harris-brand-kit@main/styles/tokens.css.
  3. When asking for a generated UI, specify the brand scope: "use the ffb brand scope" or "use the ffm brand scope". Claude Design will read the nested color.brand.ffb and color.brand.ffm maps.

Spec gap noticed: Anthropic hasn't published a public tokens.schema.json for Claude Design as of 2026-04-23 (the $schema URL in the JSON is a placeholder pointing at the docs host). The token shape here follows the W3C Design Tokens Community Group (DTCG) draft spec ($value + $type + {reference} aliasing), which Claude Design ingests cleanly. If Anthropic ships a formal schema later, swap the $schema URL and re-publish.
